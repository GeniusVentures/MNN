    Create test/op/FP4ModelTest.cpp — an E2E test validating the FP4 model conversion pipeline produces correct inference results.

    Test class: FP4ModelTest : public MNNTestCase
    Registration: MNNTestSuiteRegister(FP4ModelTest, "op/fp4/model_conversion")

    Three test scenarios within the run(int precision) method:

    **Scenario 1: CPU float vs CPU FP4 comparison**
    - Load float model: `Interpreter::createFromFile("test/models/fp4_test_model_float.mnn")`
    - Load FP4 model: `Interpreter::createFromFile("test/models/fp4_test_model_fp4.mnn")`
    - Create sessions for both with MNN_FORWARD_CPU config
    - Create identical input tensor: [1, 4, 4, 4] NCHW float, same deterministic data
    - Run inference on both
    - Compare output tensors element-by-element using checkVectorByRelativeError with rtol=0.02 (FP4 quantization introduces error)
    - Print comparison stats: max abs error, mean abs error, pass/fail

    **Scenario 2: Vulkan FP4 model inference (if Vulkan available)**
    - Vulkan availability check: `MNNGetExtraRuntimeCreator(MNN_FORWARD_VULKAN) != nullptr`
    - Skip gracefully (return true) if Vulkan unavailable
    - Load FP4 model with Vulkan backend config (MNN_FORWARD_VULKAN, BackendConfig::Precision_High)
    - Run same input, capture Vulkan output
    - Compare Vulkan output against CPU float reference using checkVectorByRelativeError with rtol=0.02
    - Compare Vulkan output against CPU FP4 output (should be identical within fp16 precision, rtol=0.01)

    **Scenario 3: Dequantize op verification**
    - Verify that both float and FP4 models produce outputs of the same shape and data type (DT_FLOAT)
    - No NaN or Inf in outputs
    - Output magnitudes are reasonable (not all zeros, not astronomical)

    Implementation patterns:
    - Use MNN::ScheduleConfig with config.type = MNN_FORWARD_CPU / MNN_FORWARD_VULKAN
    - Use Interpreter::createSession(config) then session->resize() then session->run()
    - Tensor access: getSessionInput(session, NULL), getSessionOutput(session, NULL)
    - Fill inputs with writeMap<float>() / unMap() pattern
    - Read outputs with readMap<float>()
    - Use MNNTEST_ASSERT for validation, MNN_PRINT for diagnostics

    Helper function for float model comparison:
    ```
    bool compareModels(const char* floatModelPath, const char* fp4ModelPath, 
                       MNNForwardType backend, float rtol, int precision)
    ```
    - Creates interpreters, sessions, runs inference, compares outputs
    - Returns true if all outputs match within tolerance

    Build requirements:
    - File auto-compiled by CMake's file(GLOB_RECURSE) in test/CMakeLists.txt
    - No special CMake flags needed beyond MNN_BUILD_TEST=ON
    - Model files are loaded at runtime from relative paths

    Edge cases to handle:
    - Model files not found → MNN_PRINT warning, return true (skip, not fail)
    - Vulkan runtime not available → skip Vulkan comparison, test passes if CPU comparison passes
    - Zero-size tensor outputs → MNNTEST_ASSERT fails
