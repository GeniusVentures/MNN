<objective>
Implement the D-11a padded-crop decode path that allows the CPU oracle and the Vulkan Execution to consume containers encoded from zero-padded planes (D-06) and write only the true {dimO, dimI} region to the output tensor via row-major stride crop: out[r*dimI + c] = decoded[r*paddedDimI + c].

This plan does NOT change the decode math, does NOT change shape inference (output is always true {dimO, dimI}), and does NOT require any schema evolution — paddedDimI is derived at runtime as ceil(dimI/64)*64 from the existing param->dims(). All existing non-padded paths (dimI % 64 == 0 && dimO % 64 == 0) are backward-compatible: when paddedDimI == dimI, the crop is a no-op and behavior is identical to today.

SHADER REGEN IS MANDATORY: the GLSL compute shader is modified; regenerate with python3 source/backend/vulkan/buffer/compiler/makeshader.py and commit AllShader.cpp, AllShader.h, VulkanShaderMap.cpp.

Purpose: prerequisite for Phase 9 parity tests on non-64-aligned shapes (D-08); prerequisite for Phase 11 graph-rewrite passing real model weights through the encoder.
Output: extended CPU oracle, updated CPU/Vulkan Executions, regenerated Vulkan shader artifacts.
</objective>

    1. paddedCount = static_cast&lt;size_t&gt;(paddedDimO) * paddedDimI; if paddedCount == 0 or outData == nullptr return false

    5. Return true

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Information Disclosure | CPU crop — out-of-bounds write if paddedDimI derived incorrectly | mitigate | derive as `((dimI + 63) / 64) * 64` (integer-only, cannot overflow int for dimI ≤ 65536); crop loop bounds r &lt; dimO, c &lt; dimI prevent any write beyond dimO*dimI |
| T-09-05 | Tampering | Vulkan shader — outBuffer write at r*outDimI+c must not exceed allocated outElementCount | mitigate | crop check `r &lt; outDimO &amp;&amp; c &lt; outDimI` makes the maximum write index (outDimO-1)*outDimI+(outDimI-1) = outDimO*outDimI-1 = outElementCount-1; output buffer allocated as output-&gt;elementSize() floats |
| T-09-06 | Denial of Service | CPU scratch alloc — paddedDimO*paddedDimI product for extreme dims | mitigate | paddedDimO ≤ ((65536+63)/64)*64 = 65536; product ≤ 65536*65536*4 bytes = 16GB (unreachable due to 65536 dim guard in encoder — same guard must be applied in CPU decoder path if dims come from untrusted source) |
| T-09-SC | Tampering | shader regen — stale AllShader.cpp diverges from .comp | mitigate | makeshader.py regen is a required step in Task 2; CI/review catches stale artifacts |
</threat_model>
