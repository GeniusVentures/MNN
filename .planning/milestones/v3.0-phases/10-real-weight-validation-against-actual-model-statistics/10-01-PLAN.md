    Per full-tier layer — encode via `export_weights(..., adaptive=True)` (or driving `QuadtreeEncoder` exactly as `fp4_exporter._export_v2_adaptive` does: per-64×64 superblock, same thresholds/ternary_delta/fit), collecting the per-superblock block lists (`block["size"]`, `block["mode"]`, x/y footprints). Compute:

    - Weight histogram: 64 log-spaced bins over the tensor's own value range (edges in the sidecar JSON, counts only in the markdown)
    - Fisher kurtosis `float(np.mean(((x - x.mean()) / x.std())**4) - 3.0)` in float64
    - Outlier share: fraction `|x| > μ + 6σ` AND fraction `|x| > 0.99-quantile` (both reported)
    - Leaf-size histogram: emitted leaf counts per size ∈ {64, 32, 16, 8, 4}
    - Code-mode mix: fp4 vs t158 leaf counts (`block["mode"]`); report the exporter's own `stats["layout_distribution"]` alongside (it is superblock-level, NOT the leaf histogram — label them separately)
    - Pad overhead (non-64-aligned tensors only, per D-10: measured, never re-engineered): `(ceil(dimO/64)*64 * ceil(dimI/64)*64) / (dimO*dimI)` ratio + `stats["effective_bpw"]`

    D-07 gate (per 10-RESEARCH §3 — deliberately the plain, honest metric, NOT the Laplacian-weighted internal gate): decode the container via gnus-poc `decode_v2`; for every emitted leaf, compute `mean((orig − decoded)**2)` and `max(|orig − decoded| / (|orig| + 1e-12))` restricted to the leaf's true (cropped, unpadded) footprint, in float64; compare against the per-leaf-size target (`max_mse` / `max_relative`) of the effective threshold table (overridden one if `--thresholds` was given). Per-layer worst-MSE and worst-relative = max over the layer's leaves. Layer PASSes iff every leaf meets both targets. Annotate (not fail) layers where `signal_power = mean(region²)` is near the `_kRelativeEpsilon = 1e-12` escape, so a silent ε-pass is visible (risk R3).

    Light tier (D-03): shape/framing check (container header sane for `[N,1]` projection), roundtrip decode, max-abs error — no distribution fit.

    Report (markdown, per D-05/D-12 shape): header block (model path + sha256, date, python/numpy/onnx versions, effective threshold table, exporter import root) → per-layer table (name, dims → 2-D projection, elements, tier, kurtosis, outlier shares, leaf-size histogram, code-mode mix, worst leaf MSE vs its target, worst relative vs its target, PASS/FAIL) → pad-overhead sub-table (non-aligned layers) → parity table (SKIPPED rows in this plan) → summary (gate result; explicit "no data-justified revision proposed / see delta section" placeholder for 10-03). Sidecar JSON: machine-readable mirror incl. histogram edges, per-leaf failing tuples `(layer, size, mse, relative)` for 10-03's delta loop.

    Budget: full sweep ≈ 85–120 s single-threaded (measured extrapolation). Run and commit the generated report + sidecar (generated artifacts ARE the acceptance evidence, D-05).
