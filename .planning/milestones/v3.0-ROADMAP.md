## Overview

A pytorch → onnx → mnnconvert pipeline can produce a `.mnn` file that runs SGFP4 v2 (quadtree-adaptive FP4) inference via a native `mnnconvert --sgfp4` CLI flag. Built on the v1.0 decoders (CPU + Vulkan) and v2.0 injection tool: schema `buffer:[byte]` staging + shared sidecar externalization (Phase 8), a byte-exact C++ port of the gnus-poc adaptive encoder with padded-crop decode (Phase 9), real-weight threshold validation on the AlexNet corpus (Phase 10), a graph-rewrite PostConverter pass with CLI mutex + double-processing guard (Phase 11), and a committed CPU+Vulkan E2E accuracy gate vs the FP32 baseline (Phase 12) that surfaced and fixed two correctness-critical codec defects.

## Milestone Summary

**Key Decisions:**

- Container format: external sidecar + minimal `{magic, offset, size}` descriptor extended with inline `buffer:[byte]` staging; buffer-first dispatch, sidecar fallback (Phase 8)
- Byte-exact port over approximated port: C++ encoder must be byte-identical to gnus-poc `fp4_exporter.py --adaptive` — proven (0 diff bytes), incl. RNE FP16 via explicit-rounding `half_cast` template to defeat MSVC COMDAT folding (Phase 9)
- D-07 gate reformulation: plain per-element worst-leaf MSE as hard gate; relative leaf-energy ratio as secondary (user-approved 2026-08-31) (Phase 10)
- C++ default threshold promotion DECLINED — cross-repo default parity outranks promotion; validated table opt-in via `EncodeConfig` (Phase 10)
- Buffer-staging contract for the pass (`buffer` populated, `external == {}`, no `externalPath` — zero byte I/O); `SGFP4Dequant` intentionally outside `createExecutionWithExternal` (Phase 8→11)
- 4-D conv-weight dims for conv consumers (2-D valid only for MatMul) — the significant design learning (Phase 11)
- Measure-then-lock tolerances with recorded per-backend provenance; hard Vulkan requirement (no SKIP) (Phase 12)

**Issues Resolved:**

- Spatial decode convention defect: runtime decoders moved to the normative SPATIAL padded-plane convention (flat-stream append only plane-correct for one-superblock-wide grids; exposed by tiles_x ≥ 2 shapes) — commit 54bbeaf8
- Encoder split-map bugs: global-vs-local coordinates + TL/TR/BL/BR child order fixed; C++ containers now pass strict python `decode_v2` identically to the exporter's own roundtrip
- Exit-code honesty chain: RunNetPass bool → optimizeNetImpl nullptr → cli.cpp null-guard → main exit 1; flag-off byte-identical (D-12)
- v2.0 tech debt retired: W-1 (classic_api offset convention, verified-closed at 1df51b7e), W-2 (failCleanup hoist + probe), W-3 (`SGFP4_GNUS_POC_ROOT` env override)
- Pre-existing `test/op/FP4ModelTest.cpp` link blocker (milestone workstream dead code) minimally repaired in Phase 9

**Issues Deferred / Technical Debt:**

- D-09: proposed threshold-table promotion in gnus-poc (upstream) — not this repo's change; consumers pass `EncodeConfig` explicitly
- E2E corpus is a test-time dependency (AlexNet ONNX, local path) — gate documented in `tools/fp4/README.md`, not a committed always-on CI gate
- Vulkan leg requires a real device (by design — hard FAIL, never SKIP); no-CI-Vulkan environments can't run the full gate
- `MNN_BUILD_SGFP4_TOOLS` defaults OFF — release-packaging note for the CLI binaries
- Doc debt: `02-VERIFICATION.md` still absent (v1.0 carry-over, acknowledged in v1.0 MILESTONES entry)
