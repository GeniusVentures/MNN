**Core algorithm to port (CPU reference — the ported walker, `include/MNN/SGFP4DequantUtils.hpp:141-222`):**

```cpp
// Split-map bit reader (lines 148-162) — bit-for-bit reference for the GLSL descent
struct SGFP4SplitMapReader {
    const uint32_t* words;
    int bit;
    explicit SGFP4SplitMapReader(const uint32_t* w) : words(w), bit(0) {}
    bool next(bool& out) {
        if (bit >= kSGFP4MaxQuadTreeBits) {   // kSGFP4MaxQuadTreeBits = 85 (line 68)
            return false;
        }
        out = ((words[bit >> 5] >> (bit & 31)) & 1u) != 0;
        ++bit;
        return true;
    }
};

// Iterative pre-order DFS walker (lines 188-222) — the algorithm to re-express
// as a bounded (no-stack, D-03) descent in GLSL:
inline bool sgfp4_walk_quadtree(const uint32_t* map, int& leafCount, QuadNode* leaves, int maxLeaves) {
    QuadNode stack[kSGFP4MaxQuadTreeBits];
    int top      = 0;
    stack[top++] = QuadNode{0, 0, 64};
    SGFP4SplitMapReader r(map);
    leafCount = 0;
    while (top > 0) {
        QuadNode node = stack[--top];
        if (node.n >= kSGFP4QuadTreeMinSplitSize) {  // = 8 (line 69); nodes of size 4 never read a bit
            bool split = false;
            if (!r.next(split)) { return false; }
            if (split) {
                int h = node.n / 2;
                if (top + 4 > kSGFP4MaxQuadTreeBits) { return false; }
                // Push in reverse so TL pops first (pre-order DFS): BR, BL, TR, TL
                stack[top++] = QuadNode{node.x + h, node.y + h, h}; // BR
                stack[top++] = QuadNode{node.x, node.y + h, h};     // BL
                stack[top++] = QuadNode{node.x + h, node.y, h};     // TR
                stack[top++] = QuadNode{node.x, node.y, h};         // TL
                continue;
            }
        }
        if (leafCount >= maxLeaves) { return false; }
        leaves[leafCount++] = node;
    }
    return true;
}
```

## Shared Patterns

### Bit-shift masking (applies to any new GLSL code in the MIXED branch)
**Source:** `source/backend/vulkan/buffer/execution/glsl/sgfp4_dequant.comp:63` (`read_u32_le`) and `include/MNN/SGFP4DequantUtils.hpp:158` (`SGFP4SplitMapReader::next`)
**Apply to:** every new shift expression in the split-map descent — mask the shift amount into `[0,31]` (`& 31u`) before use; never shift by a raw unmasked bit-index or level counter (GLSL ES UB otherwise).

### FP16 leaf-header unpack (reuse, don't reimplement)
**Source:** `source/backend/vulkan/buffer/execution/glsl/sgfp4_dequant.comp:70-74` (`unpackLeafHeader`, built on `unpackHalf2x16`)
**Apply to:** the MIXED branch's per-leaf header read — byte-identical leaf header format to uniform leaves (spec §6.2 Eq. 6); only the byte address computation differs.

**Apply to:** MIXED branch payload decode — identical arithmetic to uniform layouts, agnostic to how the leaf was located.
