    `data != nullptr && size >= kSGFP4FixedHeaderSize && sgfp4_read_u32_le(data) == kSGFP4Magic && data[kSGFP4VersionByteOffset] == kSGFP4Version`.

    This is the byte-level version gate (SGINJ-01) — it probes the container's own bytes (`magic=='SGF4' && version==0x02`), never trusting manifest `fp4_binary.format` (which gnus-poc mislabels `"fp4_ultra_v0.2"`). v1 fixed-payload containers have no `SGF4` magic, so this probe rejects them without decoding.
