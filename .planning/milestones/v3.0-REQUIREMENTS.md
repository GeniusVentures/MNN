## Requirements (all complete)

### Phase 8 — Schema + Sidecar Wiring

- [x] **SGV2-22**: `SGFP4DequantParam.buffer:[byte]` schema field — appended to `schema/default/CaffeOp.fbs`, headers regenerated/committed, CPU+Vulkan buffer-first decode wiring; existing artifacts and all suites green unchanged
- [x] **SGV2-23**: `RemoveParams.cpp` externalization — aligned `storeWeight` variant (16-byte-padded sidecar region, `external = {offset, true-size}`, buffer cleared after store) gated by existing `saveExternalData`/`_largeModel` flags; no new converter flag

### Phase 9 — Real-Weight C++ Encoder Port

- [x] **SGV2-24**: python→C++ encoder port — v2 adaptive quadtree encode core (FP4_AFFINE/T158_AFFINE, LAYOUT_MIXED + uniform fallbacks), byte-identical to gnus-poc `fp4_exporter.py --adaptive`; decode-parity rtol 1e-4 vs Python goldens on CPU + Vulkan; deterministic committed fixtures
- [x] **SGV2-25**: non-64-multiple tiling/padding policy — encoder zero-pads non-64-aligned planes internally; decoders gain padded-crop path decoding to TRUE dims (CPU oracle, `CPUSGFP4Dequant`, Vulkan Execution + GLSL)

### Phase 10 — Real-Weight Validation

- [x] **SGV2-26**: encoder params vs. real weight statistics — all-layer gate green on the approved AlexNet corpus with distribution evidence; committed report (`real_weight_validation_report.md` + `.json`) with per-layer stats, tier table, provenance; no real weights committed
- [x] **SGV2-27**: C++ parity on sampled real layers — `sgfp4_encode_dump.out` harness; byte-exact (rtol-1e-4 fallback documented) vs `fp4_exporter.py --adaptive`; `EncodeConfig` struct with Python-identical defaults (D-08/D-09/D-10)

### Phase 11 — Graph-Rewrite PostConverter Pass + CLI Flag

- [x] **SGV2-28**: `InsertSGFP4Dequant` PostConverter pass — runs before `ReIndexTensor`; 4 conv types across oplists + subgraphs; light-tier floor; buffer-staged contract; in-param + external-spilled weights; idempotent; encode failures transactional; 4-D conv-weight dims (recorded deviation, backward-compatible)
- [x] **SGV2-29**: `--sgfp4` CLI flag → `modelConfig::useSGFP4` with hard mutex vs `--weightQuantBits`/`--hqq`/`--fp16` (MNN_ERROR + exit 1; OQ1 exit-code fix)
- [x] **SGV2-30**: `WeightQuantAndCoding` skip-guard — early return on `inputIndexes.size() > 1` before any weight transform (incl. sparse path); doubles as v2.0 tooling-hygiene closure (W-2/W-3 retired)

### Phase 12 — End-to-End Validation

- [x] **SGV2-31**: CPU end-to-end inference correctness — `tools/fp4/e2e_validation.ps1` converts FP32 + `--sgfp4`, runs both via classic API on CPU, SGFP4 output within locked tolerances (TolAbs 10.14433 / TolRel 948.601606, measure-then-locked) vs FP32 baseline; D-11 negative leg (failed pass → exit 1, no "Converted Success!")
- [x] **SGV2-32**: Vulkan end-to-end inference correctness — same artifact via classic API + `MNN_FORWARD_VULKAN` (Precision_High, `backendType=7` asserted) vs same baseline with same tolerance; no Vulkan device = hard FAIL, never SKIP

## Out of Scope (unchanged)

- Calibration/activation-data requirements (GPTQ/AWQ/`--imatrix`-style) — breaks zero-calibration UX
- Retrofitting `IDSTEncoder`/`IDSTQuan` for SGFP4 — rejected in pivot analysis
- First-class FlatBuffers schema fields for quadtree internals — opaque blob + minimal descriptor (v1.0 lock)
- Ultra FP4 (E2M1) converter integration — separate `milestone` workstream
- Attestation / verifiable-execution — SuperGenius verifies separately
- gnus-poc `pipeline/runner.py` default-quantize fix (non-`--adaptive` v1 output) — gnus-poc-side
- D-09 threshold-table promotion in gnus-poc defaults — upstream proposal route; consumers pass `EncodeConfig` explicitly
