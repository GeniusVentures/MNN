  <action>
    Create tools/fp4/quantize_fp4.py — a standalone CLI tool that converts float .mnn model Conv2D/InnerProduct weights to FP4 E2M1 format.

    Library imports: argsparse, json, os, struct, numpy (no torch dependency — pure numpy). Use sys.path.insert to reach MNNConvert.

    Implement two core functions:
    1. encode_fp4_e2m1(float_val) → uint8: Encode a float32 value to E2M1 4-bit nibble. E2M1 format: 1 sign bit | 2 exponent bits (bias=1) | 1 mantissa bit. Steps:
       - Handle sign: s = 1 if val < 0 else 0, val = abs(val)
       - If val == 0: return 0x00 (positive zero, exponent=0, mantissa=0)
       - If val is Inf: return 0x60 | s<<3 (exponent=3, mantissa=0, sign bit)
       - If val is NaN: return 0x70 | s<<3 (exponent=3, mantissa=1, sign bit)
       - Normal: find exponent e = floor(log2(val)), biased_e = e + bias = e + 1
       - If biased_e >= 3: saturate to max (0x60 | s<<3, value 6.0)
       - If biased_e <= 0: subnormal — mantissa_bit = round((val / 2^(-1)) * 2), encoded = s<<3 | 0 | mantissa_bit
       - Otherwise normal: mantissa_bit = round((val / 2^e - 1.0) * 2), encoded = s<<3 | (biased_e<<1) | mantissa_bit
    2. quantize_tensor_weights(float_list, nbits=4) → (packed_bytes, per_channel_scales): For each output channel, pack FP4 values 2-per-byte (low nibble first per D-03), compute per-channel scale = max_abs_float / max_e2m1_value. Return packed bytearray and scale list.

    Main pipeline (main function with --input, --output, --bits=4, --sym arguments):
    a. Convert .mnn to JSON: run `MNNConvert -f MNN --modelFile <input.mnn> --jsonFile <tmp.json>` via subprocess
    b. Load JSON with json.load()
    c. Iterate over oplists — for each op with type "Convolution" or "InnerProduct":
       - If op["main"].get("weight") is non-empty list of floats:
         - weights = op["main"]["weight"]
         - oc = op["main"]["common"]["outputCount"] (for Conv2D) or op["main"]["outputCount"] (for InnerProduct)
         - Iterate over oc channels, encode each channel's weights to FP4
         - Compute per-channel scale = max(abs(channel_weights)) / max_e2m1_value (=6.0)
         - Store packed bytes + per-channel scales in symmetricQuan
    d. For each quantized op, set op["main"]["symmetricQuan"] = {
         "nbits": 4,
         "weight": list of packed bytes as ints,
         "scale": per_channel_float_scales,
         "bias": [0] * oc,
         "outputDataType": 0,   # DT_FLOAT — signals E2M1 encoding to runtime
         "clampMin": 0,
         "clampMax": 0
       }
       Delete op["main"]["weight"] to save space (keep weight for float reference).
    e. Write modified JSON to tmp_out.json
    f. Convert back to .mnn: run `MNNConvert -f JSON --modelFile <tmp_out.json> --MNNModel <output.mnn>` via subprocess
    g. Clean up temporary JSON files

    CLI: argparse with --input (required, path to float .mnn), --output (required, path output .mnn), --bits (default 4), --sym (default True).

    Error handling: validate input file exists, check MNNConvert availability, handle empty weight tensors gracefully, print per-op quantization stats (size ratio, max encoding error).

    Do NOT use torch — the tool should work without PyTorch. Do NOT modify MNNConvert source — only invoke it via subprocess.
  </action>

    - Class CPUFP4Dequant : public Execution
    - Constructor takes Backend* (no precision flag needed — CPU always does FP32 intermediate)
    - Virtual destructor (no-op)
    - Single virtual method: ErrorCode onExecute(const std::vector<Tensor*>& inputs, const std::vector<Tensor*>& outputs) override
    - Header guard: #ifndef CPUFP4Dequant_hpp / #define CPUFP4Dequant_hpp / #endif

    Step 2: Create source/backend/cpu/CPUFP4Dequant.cpp. Pattern from CPUDequantize.cpp registration:
    - Include "CPUFP4Dequant.hpp", "core/Macro.h", "core/TensorUtils.hpp", "MNN/FP4DequantUtils.hpp"
    - Constructor body: empty (no GPU pipeline setup needed)
    - onExecute: 
      a. input = inputs[0] (DT_UINT8 tensor with FP4-packed bytes), output = outputs[0] (DT_FLOAT tensor)
      b. elementCount = output->elementSize()
      c. srcBytes = (elementCount + 1) / 2  (2 FP4 values per byte, D-03)
      d. Read packed bytes from input->host<uint8_t>()
      e. Call MNN::dequant_fp4_packed_cpu(packed_data, output->host<float>(), elementCount) from FP4DequantUtils.hpp
      f. Return NO_ERROR
    - Creator class CPUFP4DequantCreator : public CPUBackend::Creator:
      - onCreate returns new CPUFP4Dequant(backend) — unconditionally, since any Dequantize op on CPU with FP4 data should use this
      - BUT must co-exist with existing CPUDequantizeCreator (also registered for OpType_Dequantize). 
      
      **Coexistence strategy**: CPUFP4DequantCreator checks the input tensor's data type or size to determine if the data is FP4. If input element size suggests 2-byte-per-value (FP4 packed), use FP4Dequant; otherwise return nullptr so the fallback CPUDequantizeCreator handles it.
      
      Detection: input Tensor's getType() will be DT_UINT8 for packed FP4 bytes. The output tensor type will be DT_FLOAT. The packed byte size = ceil(elementCount/2). If the input byte size exactly matches this packed pattern AND is smaller than typical int8 data for the same element count, treat as FP4.
      
      Simpler detection: Check if Dequantize op's main type is DT_UINT8 AND the input->getType().bytesSize() is approximately elementCount/2 (indicating packed 4-bit). The input Tensor has its type info set by the model loader from the Blob dataType field (DT_UINT8 for packed bytes).

    - Register: static bool gResistor = []() { CPUBackend::addCreator(OpType_Dequantize, new CPUFP4DequantCreator); return true; }();
