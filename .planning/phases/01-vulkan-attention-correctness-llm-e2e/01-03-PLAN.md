<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Model file -> Vulkan backend | LLM model weights loaded from file cross into GPU memory; corrupted model could trigger undefined GPU behavior |
| User prompt -> llm_demo | Untrusted text input flows through the entire attention pipeline; GPU shader robustness ensures valid output even for edge-case inputs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | llm_demo model loading | accept | Model integrity is outside Phase 1 scope; MNN Interpreter validates FlatBuffers format on load |
| T-03-02 | Denial of Service | Large context windows (>4096 tokens) | accept | KVCache capacity bounded by ensureCapacity MNN_ASSERT; OOM returns error, does not crash |
| T-03-03 | Information Disclosure | llm_demo output logging | accept | Test output contains only generated text, no model internals or PII |
</threat_model>
