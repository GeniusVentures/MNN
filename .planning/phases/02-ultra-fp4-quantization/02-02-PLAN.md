**Function 1: `dequant_e2m1_cpu(uint8_t nibble) → float`**
Implements the E2M1 decode per D-01:
```cpp
inline float dequant_e2m1_cpu(uint8_t nibble) {
    uint8_t s = (nibble >> 3) & 0x1;
    uint8_t e = (nibble >> 1) & 0x3;
    uint8_t m = nibble & 0x1;
    float sign = (s == 1) ? -1.0f : 1.0f;
    if (e == 0) {
        // Subnormal: (-1)^s × m × 0.5 (bias=1)
        return sign * static_cast<float>(m) * 0.5f;
    }
    if (e == 3) {
        // Special: Inf (m=0) or NaN (m=1)
        return (m == 0) ? sign * INFINITY : NAN;
    }
    // Normal: (-1)^s × 2^(e-1) × (1 + m/2)
    float expVal = static_cast<float>(1 << (e - 1));
    float mantissa = 1.0f + static_cast<float>(m) * 0.5f;
    return sign * expVal * mantissa;
}
```
This is the CPU golden reference. The GLSL implementation in `fp4_dequant.comp` must produce matching values within float tolerance.

**Function 2: `pack_fp4_byte(uint8_t low_nibble, uint8_t high_nibble) → uint8_t`**
Packs two FP4 values into one byte per D-03 packing layout:
```cpp
inline uint8_t pack_fp4_byte(uint8_t low_nibble, uint8_t high_nibble) {
    return (low_nibble & 0x0F) | ((high_nibble & 0x0F) << 4);
}
```
Low nibble (bits 0-3) = first FP4 value, high nibble (bits 4-7) = second FP4 value. This matches the little-endian nibble ordering used by `fp4_dequant.comp`.

**Function 3: `dequant_fp4_packed_cpu(const uint8_t* packed, float* output, size_t elementCount)`**
Convenience function that dequantizes a packed FP4 buffer:
```cpp
inline void dequant_fp4_packed_cpu(const uint8_t* packed, float* output, size_t elementCount) {
    for (size_t i = 0; i < elementCount; ++i) {
        size_t byteIdx = i >> 1;
        uint8_t byte = packed[byteIdx];
        uint8_t nibble = (i & 1) ? (byte >> 4) : (byte & 0x0F);
        output[i] = dequant_e2m1_cpu(nibble);
    }
}
```
Even indices → low nibble, odd indices → high nibble (same as fp4_dequant.comp swizzling).
