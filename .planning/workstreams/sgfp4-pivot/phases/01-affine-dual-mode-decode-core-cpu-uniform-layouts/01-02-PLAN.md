Add the reference Python encoder for uniform-layout SGFP4 v2 containers and the CPU unit tests that validate round-trip decode, closing SGV2-07 and behaviorally verifying the decode core built in Plan 01-01 (SGV2-01..06).

The encoder (`tools/fp4/encode_sgfp4.py`) is a NEW file that implements the spec's exemplary affine encode (Section 4.4) for both code modes plus per-block mode selection, and writes the v2 self-framed container (Section 6.1/6.2) for all five uniform layouts. The tests (`test/op/SGFP4DequantTest.cpp`) exercise three layers: (1) cross-language round-trip by decoding encoder-produced fixtures and comparing to expected weights within the encoder's error bound; (2) hand-built C++ edge cases that a well-formed encoder cannot emit (ternary reserved symbol, FP16 precision boundary, malformed/out-of-bounds negative cases, B != 0 mod 4 alignment); (3) op-level end-to-end decode through the CPU backend using the `rtmgr->setExternalFile` plumbing resolved in Plan 01-01.

Purpose: Prove both code modes and all uniform layouts round-trip on CPU, giving the Vulkan port (Phase 3) a trusted reference and closing the Nyquist behavioral gate for Phase 1.

Output: `tools/fp4/encode_sgfp4.py`, `test/op/SGFP4DequantFixtures.h` (encoder-generated, committed), `test/op/SGFP4DequantTest.cpp`. Covers SGV2-07.

Encoding math (spec Section 4.4), per leaf/block:
- FP4_AFFINE (mode 0): bias = mean(w); search 16 log-spaced S candidates over [0.5, 1.5] * (max|w| / 7), pick the S minimizing round-trip MSE; codes c = clip(round((w - bias)/S), -8, 7).
- T158_AFFINE (mode 1): bias = mean(w); S = mean(|w - bias|); codes by thresholding at tau = S/2 -> {-1, 0, +1} (|x| < tau -> 0 else sign(x)).
- Clip S and bias to the FP16 range (+/-65504) before packing (spec Section 3.2).
- Per-block mode selection: compute L2 round-trip error for both modes; choose mode 1 iff e_T158 <= (1 + 0.10) * e_FP4 (Eq.5, default eps=0.10).

Leaf-header packing (spec Eq.6 inverse): word = (half_bits(S) << 16) | (half_bits(bias) & 0xFFF0) | (mode & 0x1). Use numpy float16 to get the FP16 bit patterns. The low 4 bits carry flags (bit0 = mode; bits1-3 reserved 0) — this is the 12-bit truncated bias the decoder recovers via bias = half(h & 0xFFF0). Use named constants for the shift/masks (no magic numbers).

Payload packing (spec Section 4.3, little-endian uint32 words; use named constants):
- mode 0: n*n codes, 8 nibbles/word, nibble i at bit 4*(i mod 8); n*n/8 words; store 4-bit two's-complement (negative c stored as c & 0xF); pad payload to a 16-byte multiple.
- mode 1: n*n codes, 16 symbols/word, symbol i at bit 2*(i mod 16); mapping 0->00, +1->01, -1->10; n*n/16 words; pad to a 16-byte multiple.

Container writer (spec Section 6.1/6.2, all little-endian): fixed 16-byte header ('SGF4' + version 0x02 + B:uint32 + 7 pad bytes); record_offsets[B] (uint32 each) starting at byte 16, then pad1 zeros so the record region begins at align16(16 + 4*B); records in row-major macroblock order, each 16-byte aligned within the region and each record_offsets[b] relative to the region start. Each uniform record = sb_header:uint32 (layout enum in bits 0-2, no split map) + block_headers[N] (uint32 each) + pad to 16 bytes + payloads[N] (each padded to 16 bytes). Support all five uniform layouts (Table 3): UNIFORM_64->(n=64,N=1), UNIFORM_32->(32,4), UNIFORM_16->(16,16), UNIFORM_8->(8,64), FULL_4x4->(4,256), with leaves in row-major raster order. Input weight matrices are conceptually padded with zeros to multiples of 64 in both dims.

CLI / entry points:

Cover both modes x all 5 uniform layouts plus the B=3 alignment case. This header is the cross-language oracle the C++ test decodes and compares against.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| encoder-produced container -> CPU decoder | The encoder is the reference oracle; a wire-format mistake (misalignment, wrong leaf-header bits) silently corrupts every downstream decode and the future Vulkan port — the round-trip tests are the guard |
| test-authored temp sidecar files -> filesystem | The op-level test writes/reads temp `.mnn.weight` files; test-authored, not untrusted, but must not leak or collide |
