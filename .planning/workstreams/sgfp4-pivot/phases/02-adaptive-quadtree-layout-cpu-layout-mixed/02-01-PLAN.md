<objective>
Teach the header-only CPU decode core `dequant_sgfp4_container_cpu()` (in `include/MNN/SGFP4DequantUtils.hpp`) to accept the currently-rejected `LAYOUT_MIXED` (enum 4) record by walking the 12-byte/3-word pre-order-DFS quadtree split-map with an iterative fixed-size stack, then decoding variable-size leaves in traversal order.

</objective>
