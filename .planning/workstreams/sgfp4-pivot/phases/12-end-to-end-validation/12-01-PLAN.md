<objective>
Implement the SGFP4-scoped RunNetPass error-escalation fix (D-11) with zero flag-off impact (D-12): when `--sgfp4` is set and `InsertSGFP4Dequant` fails or transactionally skips, mnnconvert exits non-zero with a clear `MNN_ERROR` and never prints "Converted Success!" over a silently-FP32 artifact.

Purpose: Phase 12's E2E script (Plan 12-02) gates on `MNNConvert`'s exit code — the honesty of that exit code is a prerequisite for SGV2-31/SGV2-32 gating and closes the flag left by Phase 11 verification.

Output: Failure-propagation chain `RunNetPass(false) → optimizeNetImpl(nullptr) → convertModel(false) → main(exit 1)`, all gated on `useSGFP4`; regression suites stay green.

Planner decisions locked (per RESEARCH open questions):
- **OQ1 = strictest D-12 reading:** `MNNConverter.cpp` main propagates non-zero ONLY when `modelPath.useSGFP4` is true and `convertModel` returned false. Flag-off failure exit codes stay 0 (byte-identical behavior). Unconditional propagation is noted in a code comment as an explicit follow-up, NOT implemented.
- **OQ4 = signature change `void RunNetPass` → `bool RunNetPass`:** all existing call sites ignore the return value (compiles unchanged, zero behavior change); only the SGFP4 batch site in `optimizeNetImpl` consumes it. `PostConverter.hpp:36` declaration updated; `TestSGFP4Converter.cpp` call sites compile unchanged.
</objective>
