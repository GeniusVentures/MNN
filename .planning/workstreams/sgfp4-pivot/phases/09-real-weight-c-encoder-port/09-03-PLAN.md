<objective>
Create the deterministic golden fixture generator (D-05) for real (non-64-aligned) weight shapes and commit its output as a C-array fixture header that the parity tests (Plans 09-04 and 09-05) import.

The generator mirrors tools/fp4/author_structured_fixture.py: it calls gnus-poc's FP4Exporter.export_weights(..., adaptive=True) on seeded pseudo-random FP32 weight matrices of non-64-aligned shapes, then emits a C-array header with three arrays per fixture: inputWeights (FP32 source plane), container (Python-encoded SGFP4 v2 bytes), and expected (decoded float reference). This enables Plan 09-04 to feed inputWeights into sgfp4_encode::encode() and compare C++-decode vs Python-decode at rtol 1e-4.

Purpose: provides the golden oracle data that both CPU and Vulkan parity tests (Plans 09-04, 09-05) depend on.
Output: tools/fp4/author_real_shape_fixture.py and test/op/SGFP4RealShapeFixtures.h (committed generated output).
</objective>
