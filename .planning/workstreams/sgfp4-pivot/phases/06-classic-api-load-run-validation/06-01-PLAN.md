<objective>
Refactor the Phase 5 injection tool into a shared core header so the Phase 6 test can drive injection in-process (D-12). Move every function in `tools/fp4/sgfp4_inject.cpp` except `main()` into a new header-only `tools/fp4/sgfp4_inject_core.hpp` under `namespace sgfp4_inject`, mark all free functions `inline`, and rename the CLI worker `injectMain` → `run`. `tools/fp4/sgfp4_inject.cpp` shrinks to `#include "sgfp4_inject_core.hpp"` + a one-line `main()` returning `sgfp4_inject::run(argc, argv)`.

Purpose: This is a mechanical move with zero behavior change. It is the enabling step for Plan 06-02, which must call the injection core in-process (no subprocess, no re-implementation per D-12). The `sgfp4_inject.out` executable target must build and behave exactly as Phase 5 left it.

Output: `tools/fp4/sgfp4_inject_core.hpp` (the moved core, `namespace sgfp4_inject`, `inline int run(...)`) and a thinned `tools/fp4/sgfp4_inject.cpp`. No CMake change is required — `tools/fp4/CMakeLists.txt` already globs `*.hpp` and the header is inert in the executable source list.
</objective>
