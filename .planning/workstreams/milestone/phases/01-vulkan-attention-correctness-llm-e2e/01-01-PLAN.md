<objective>
Replace the fragile global memory barrier with proper Vulkan buffer memory barriers for KV cache synchronization (VULK-06), and move causal mask generation from CPU O(N\u00b2) memory copy to a GPU compute shader (VULK-07). Both changes touch VulkanAttention.cpp \u2014 the file is 1505 lines and is the sole implementation of the Vulkan Attention operator.

Purpose: Eliminate two correctness weak points: (1) the global memory barrier after KV update that cannot track which buffers actually need synchronization, and (2) the CPU-side lower-triangular mask construction that allocates and uploads O(queryLen \u00d7 totalLen) floats per token.
Output: VulkanAttention.cpp with buffer barrier fix, new attention_mask_gen.comp GLSL shader, and regenerated shader autogeneration artifacts.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CPU host -> GPU device | Vulkan buffer contents cross the PCIe/interconnect boundary; stale or corrupted buffers from prior dispatches could produce incorrect KV cache data or mask values |
| VulkanAttention::onEncode -> onBeforeExecute | Descriptor set bindings are written in onBeforeExecute based on buffer handles that may have been reallocated since onEncode recorded the command buffer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | VulkanAttention::onEncode barrier | mitigate | Replacing VkMemoryBarrier with VkBufferMemoryBarrier targeting specific KV cache buffers (Task 1) ensures only the buffers that the update shader wrote are synchronized \u2014 prevents stale reads of unrelated buffers |
| T-01-02 | Tampering | VulkanAttention::onBeforeExecute mask | mitigate | Moving mask generation to GPU shader eliminates the CPU-side copyFromHostTensor path that could be out-of-sync with actual tensor dimensions (Task 2) |
| T-01-03 | Information Disclosure | attention_mask_gen.comp | accept | Mask generation shader writes only to the designated output buffer; no PII or secrets involved \u2014 accept |
| T-01-04 | Denial of Service | KVCache capacity overflow | accept | Existing MNN_ASSERT bounds checks in ensureCapacity prevent OOM \u2014 accept |
</threat_model>
