Create `fp4_dequant.comp` in the glsl/ directory. Design:

**Binding layout:**
- binding=0: readonly storage buffer `{ uint SrcRaw[]; }` — packed FP4 source data (2 values per byte)
- binding=1: writeonly storage buffer `{ FLOAT Dst[]; }` — output FP16 or FP32 values (FLOAT is defined by makeshader.py header, do NOT redefine)
- binding=2: uniform `{ uint elementCount; uint srcBytes; }` — output element count and source byte count (follows the VulkanSoftmax/VulkanLayernorm uniform buffer pattern — NOT push_constant)

**Workgroup:** `local_size_x = 256, local_size_y = 1, local_size_z = 1` — matches Phase 1 `attention_mask_gen.comp` pattern for 1D dispatch.

**E2M1 decode function `dequant_e2m1(uint nibble) → FLOAT`** per D-01:
- Extract s = (nibble >> 3) & 1, e = (nibble >> 1) & 3, m = nibble & 1
- sign = (s == 1) ? FLOAT(-1.0) : FLOAT(1.0)
- Subnormal (e == 0): value = sign × m × 0.5 (D-01: bias=1, so subnormal at e=0 gives 2^(-1) × m/2 = m × 0.5)
- Normal (e == 1,2): value = sign × 2^(e-1) × (1 + m/2)
- Special (e == 3): m=0 → Inf, m=1 → NaN. Return `FLOAT(1.0/0.0)` for Inf/NaN (GLSL: positive/negative infinity from sign multiplication)

**main() logic:**
- Compute `idx = gl_GlobalInvocationID.x`; guard: `if (idx >= elementCount) return;`
- Compute byteIndex = idx >> 1, nibbleOffset = idx & 1
- Guard: if byteIndex >= srcBytes, write 0.0 and return
- Read word from SrcRaw, decode the correct nibble per D-03 swizzling:
  - nibbleOffset == 0: low nibble = byte & 0x0F (first FP4 value in the byte)
  - nibbleOffset == 1: high nibble = (byte >> 4) & 0x0F (second FP4 value)
- `Dst[idx] = dequant_e2m1(nibble);`

**Swizzle note per D-03:** The nibble ordering is little-endian within each byte — low nibble (bits 0-3) is the first FP4 value, high nibble (bits 4-7) is the second. This is the GLSL-optimized access pattern: contiguous thread→contiguous byte, alternating nibble within the same word access.

**Shader naming convention:** The file name `fp4_dequant.comp` means makeshader.py will produce pipeline keys:
- FP32 variant: `glsl_fp4_dequant_comp`
- FP16 variant: `glsl_fp4_dequant_FP16_comp`
The `FLOAT`/`FLOAT2`/`FLOAT4` macros in the `.comp` body expand correctly for both variants since makeshader.py prepends the appropriate header.

**Anti-patterns to avoid:**
- Do NOT redefine FLOAT/FLOAT2/FLOAT4 — makeshader.py provides these
- Do NOT use `float` directly in shader arithmetic — always use `FLOAT`
- Do NOT hardcode local_size that differs from Vulkan pipeline creation
- Do NOT use `#version` directive — makeshader.py prepends it
